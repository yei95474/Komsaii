Perfect! 🚀 Word problems make these concepts way more fun and real. Here’s a set of **word problems** (no code yet, just math → algorithm thinking). They’re all in the “same family” as integer reversal: digit manipulation, division/modulo tricks, base conversion, etc.

---

## 🔢 Digit manipulation problems

1. **Sum of Digits – The Cashier’s Mistake**
   A cashier accidentally adds up all the digits of a customer’s ID number `4927`.
   What is the total?
   *(Hint: Peel digits with `% 10`, keep adding.)*

2. **Product of Digits – The Lock Code**
   A lock only opens if you multiply all the digits of a 4-digit code and the result is `0`.
   Given a code like `4065`, does the lock open?

3. **Palindrome – The Magic Mirror**
   A wizard claims your ticket number reads the same forwards and backwards.
   Check if ticket `12321` is magical.

4. **Armstrong Number – The Special Number Plate**
   A car’s plate number is “407”.
   If you cube each digit and add them, does it equal the original plate number?

---

## ⚙️ Number representation

5. **Binary Conversion – Robot Commands**
   A robot understands commands only in binary.
   Convert the decimal number `25` into binary so the robot can execute it.

6. **Octal Conversion – Submarine Depths**
   A submarine records depths in octal.
   Convert `64` meters (decimal) into octal.

7. **Digit Extraction – ATM PIN**
   An ATM machine wants the 3rd digit from the right of your PIN `987654`.
   Which digit is it?

---

## 🔄 Algorithmic patterns

8. **First and Last Digit – Lucky Phone Number**
   A phone company says a number is lucky if its first and last digits are equal.
   Is `8128` lucky?

9. **Count Digit Frequency – Election Votes**
   A ballot machine records vote IDs. If the number is `2233445`, how many times was the digit `3` pressed?

10. **Digit Palindrome Check – Train Ticket**
    Train tickets with palindromic numbers get a free ride.
    Does ticket `76567` qualify?

---

## 🧩 Classic extras

11. **GCD – Chocolate Sharing**
    Two kids have `36` and `48` chocolates. They want to split them into equal groups with no leftovers.
    What’s the largest group size they can both use?

12. **Prime Check – Security Code**
    A vault only opens if the code is a prime number.
    Is `97` a valid code?

13. **Factorial – Counting Orders**
    A bakery has `5` different cakes. In how many ways can they be arranged on a shelf?
