Overview

This exercise has three parts. Part A asks you to annotate the time and space complexity of five C++ code fragments using Big-O notation, plus a one-sentence justification for each. Part B asks you to trace four operations on a singly linked list by drawing pointer diagrams. Part C asks you to complete a complexity comparison table for arrays versus singly linked lists.
